## Espacements

| Token | Valeur | Usage |
|-------|--------|-------|
| `spacing/padding-block` | 24px | Padding des blocs de contenu (OBLIGATOIRE) |
| `spacing/margin-desktop` | 80px | Marges latérales desktop |
| `spacing/margin-mobile` | 24px | Marges latérales mobile |
| `spacing/gap-sm` | 8px | Espacement petit (entre éléments proches) |
| `spacing/gap-md` | 16px | Espacement moyen (entre blocs) |
| `spacing/gap-lg` | 24px | Espacement large (entre sections) |
| `spacing/gap-xl` | 40px | Espacement extra-large (hero, footer) |

## Border Radius

| Token | Valeur | Usage |
|-------|--------|-------|
| `radius/sm` | 4px | Petits éléments, inputs, lignes FAQ |
| `radius/md` | 6px | Boutons, inputs formulaire |
| `radius/lg` | 8px | Cards, images, conteneurs |
| `radius/xl` | 12px | Grandes cards, hero images |
| `radius/full` | 18px+ | Badges, pills, cercles |

## Ombres

| Token | Valeur | Usage |
|-------|--------|-------|
| `shadow/card` | `0 4px 12px rgba(0,0,0,0.1)` | Cards produits |
| `shadow/button` | `0 2px 4px rgba(0,144,153,0.2)` | Boutons primaires (hover) |

## Grille

- **Desktop** : 1440px de large, contenu centré, marges 80px
- **Mobile** : 375px de large, marges 24px
- **Padding blocs** : 24px (obligatoire selon le brief)
- **Colonnes Desktop** : 3 colonnes pour les produits/caractéristiques
- **Colonnes Mobile** : 1 colonne (stack vertical), 2 colonnes pour les petites cards
