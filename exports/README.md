## Procedure d'export depuis Penpot

1. Ouvrir le fichier cef dans Penpot
2. Selectionner la page a exporter
3. File > Export (ou Ctrl/Cmd + E)
4. Choisir le format (PNG recommande, echelle 1x ou 2x)
5. Enregistrer dans ce dossier

## Export par lot (toutes les pages)

1. Selectionner toutes les pages dans le panel Pages
2. File > Export > Export pages
3. Format : PNG, echelle 1x
4. Enregistrer dans ce dossier
